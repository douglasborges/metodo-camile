# Método ET · Estudos da Camile · CGU

Aplicação independente da Camile, baseada no Método ET, com foco na **CGU — Auditoria e Fiscalização**.

## Ciclo inicial

Português → Direito Constitucional → Informática e Dados.

Cada ocorrência usa 1h como referência mínima de planejamento, mantendo registro por tempo real.

## Dados separados

- LocalStorage: `metodo-et:camile:v1`
- Backup Google Drive: `Metodo ET - Camile - Dados.json`
- Propriedade de nuvem: `camile-cloud-v1`

Os dados desta aplicação são independentes da Método ET do Douglas.
