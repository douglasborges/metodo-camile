# Método ET · Estudos da Camile · CGU

Aplicação independente da Camile, baseada no Método ET, com foco na **CGU — Auditoria e Fiscalização**.

## Ciclo inicial

**Português → Direito Constitucional → Informática e Dados**

Cada ocorrência usa **1h como referência mínima**, sempre registrando o tempo real.

## Carga de estudo

- **Mínimo diário:** 3h.
- **Meta semanal:** 20h.
- Dias de 3h30 ou mais são naturalmente aproveitados para alcançar as 20h semanais.
