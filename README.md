# Método ET · Camile · CGU 2026

Aplicação independente da Camile, baseada no Método ET, em **pós-edital para a CGU — Auditor Federal de Finanças e Controle · Especialidade Auditoria**, preservando o TCU como objetivo secundário de longo prazo.

## Prazo e carga

- **Prova:** 13/12/2026.
- **Referência diária:** 5h líquidas.
- **Meta semanal:** 30h líquidas.
- **Metas ET:** 8 metas semanais de 30h, de 13/10 a 07/12.
- **Sprint final:** 08/12 a 12/12, sem teoria ampla nova.
- O tempo real é sempre registrado: a referência de bloco não é cota artificial.

## Ciclo pós-edital

**Português → DCON → AFO → TI/Dados → Administração Pública → Diversidade → AFO → DAD → Políticas Públicas → Auditoria → AFO**

Cada Meta exige:
- 30h reais;
- 2 voltas completas do ciclo;
- 22 ocorrências na ordem;
- núcleo de referência de 26h + margem de 4h para baterias, checkpoints, legislação, questões e variações reais.
